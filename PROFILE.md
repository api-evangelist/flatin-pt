# flatin.pt

Portuguese property-tax APIs providing keyless access to IMI rates for all 308 municipalities and IMT/stamp duty purchase-cost calculations, sourced from official Autoridade Tributária tables. Offers a REST API, remote MCP server, llms.txt, and CC BY 4.0 open dataset.

## APIs

- **flatin.pt API** — Keyless REST API for Portuguese IMI rates and IMT/stamp duty calculations, with a remote MCP server exposing four agent tools and an llms.txt for agent discovery. (`https://flatin.pt/api/v1`)

> Full agent-native and traditional-API footprint, all keyless and no-signup. REST API endpoints include GET /api/v1/imi/rates, GET /api/v1/imi/rates.csv, GET /api/v1/imi/rates/{codigo}, POST /api/v1/imt/calculate. OpenAPI 3.1.0 confirmed live. Remote MCP server at https://flatin.pt/mcp uses Streamable HTTP transport (no SSE; GET returns 405), registry name pt.flatin/property-taxes, source repo https://github.com/flatinpt/mcp, tools: imt_calculate, imi_rate, imi_annual_cost, request_consultation. CC BY 4.0 CSV dataset at https://flatin.pt/api/v1/imi/rates.csv. Additional well-knowns: /.well-known/apis.json, /.well-known/api-catalog, /api/plans.json, /api/rate-limits.json, /api/spectral.yaml, /api/changelog.json. No GraphQL/AsyncAPI/Postman collection.
